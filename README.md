# kimi-skills

A curated library of **71 Agent Skills** (`.skill` packages) for Kimi and other Claude-Code-compatible agents. Each package bundles a `SKILL.md` plus supporting scripts, fixtures, and reference material, ready to drop into a skills directory.

## What's here

Highlights (author's picks):

| Skill | What it does |
|---|---|
| `rea` | Reverse-engineer apps engine-free — static JS/Electron analysis (modules, IPC channels, routes, storage) without executing the target |
| `numpy-gpt2` | Run OpenAI's real GPT-2 (124M) with an inference engine written from scratch in pure NumPy — hand-written safetensors loader, byte-level BPE, full 12-layer transformer forward pass |
| `tiny-gpt-lab` | Train a tiny GPT from scratch on any text corpus, live, in about a minute on CPU |
| `quantum-sim` | Stabilizer-rank quantum circuit simulation — Bell/GHZ states, teleportation, error correction |
| `llm4decompile` | Decompile Linux x86-64 binaries back to readable C with an LLM trained for decompilation |
| `music-gen` | Compose original music locally with open-weights MusicGen |
| `bumblebee` | Read-only supply-chain security scanner (npm/PyPI/Go/RubyGems/MCP servers/extensions) |
| `hallmark` | Anti-AI-slop design skill for pages, audits, and redesigns |
| `skill-router` | Automatic skill/tool selection with IDF-weighted routing over the registry |
| `skill-test-suite` | QA harness for .skill libraries — archive integrity, router accuracy, registry consistency |

## Installing a skill

**Option A — with the skills CLI:**

```sh
npx skills add ndubs97/kimi-skills --skill rea
```

**Option B — manual:** download `packages/<name>.skill`, unzip it so the folder (`<name>/SKILL.md`) lands in your skills directory (e.g. `~/.agents/skills/` or `~/.user/skills/`), restart your agent.

## Provenance and licenses

These skills come from a mix of sources: official/vendor skill packs (Anthropic, Vercel, Sentry, n8n, Addy Osmani, Jeff Allan, Matt Pocock, wshobson, baoyu), open community collections (alirezarezvani, jeffallan, scientific-agent-skills, ai-research-skills), and originals authored in this project (rea, numpy-gpt2, tiny-gpt-lab, quantum-sim, llm4decompile, music-gen, skill-router, skill-test-suite, hallmark, bumblebee). Licenses vary per package — check the individual `SKILL.md` / bundled license files. Do not redistribute packages whose bundled licenses prohibit it.

## Security notes

- `hackingtool` and security-related skills are for systems you own or are explicitly authorized to test.
- RE skills (`rea`, `llm4decompile`) are for software you own or are authorized to analyze.
- `freellmapi` routes prompts through third-party free endpoints — do not send sensitive data.

## How the packages got here

The binaries are staged via a file-host bridge and imported by `.github/workflows/import-skills.yml`, which downloads each package listed in `URLS.json`, verifies it is a valid zip containing a `SKILL.md`, records its sha256 and size into `MANIFEST.json`, and commits the results to `packages/`. Every entry in `MANIFEST.json` is therefore hash-verified at import time.
